# sofit

sofit is a single-user, mobile-first fitness and nutrition web app. It uses Google sign-in, stores the profile/goal/streak data in one Firestore document per user, and serves as a Firebase Hosting PWA.

## Local Setup

1. Install dependencies:

   ```sh
   npm install
   ```

2. Create a local Firebase env file:

   ```sh
   cp .env.example .env
   ```

3. In Firebase Console, create or open your project, then add a Web app and copy its config values into `.env`:

   ```sh
   VITE_FIREBASE_API_KEY=...
   VITE_FIREBASE_AUTH_DOMAIN=...
   VITE_FIREBASE_PROJECT_ID=...
   VITE_FIREBASE_STORAGE_BUCKET=...
   VITE_FIREBASE_MESSAGING_SENDER_ID=...
   VITE_FIREBASE_APP_ID=...
   ```

4. Enable Google sign-in:

   Firebase Console -> Authentication -> Sign-in method -> Google -> Enable.

5. Install Cloud Functions dependencies:

   ```sh
   cd functions
   npm install
   cd ..
   ```

6. Run the app:

   ```sh
   npm run dev
   ```

## Firestore

The app stores one document per signed-in user:

```txt
users/{uid}
  profile: { age, sex, heightCm, weightKg }
  goal: "strength" | "cardio" | "flexibility" | "health" | "weightloss"
  generatedPlan: { weeklyMeals, weeklyWorkouts, groceryList, helpfulNotes }
  doneDates: ["YYYY-MM-DD"]
  updatedAt: server timestamp
```

Publish the included Firestore rules before sharing the app:

```sh
firebase deploy --only firestore:rules
```

The required rule is:

```txt
match /users/{uid} {
  allow read, write: if request.auth != null && request.auth.uid == uid;
}
```

## Deploy

1. Set the OpenAI API key as a Firebase Functions secret:

   ```sh
   firebase functions:secrets:set OPENAI_API_KEY
   ```

   The key is used only inside the Cloud Function. Do not put it in `.env` or the React app.

2. Build the app:

   ```sh
   npm run build
   ```

3. Deploy Hosting, rules, and Functions:

   ```sh
   firebase deploy --only hosting,firestore:rules,functions
   ```

The Firebase web config is read from Vite env vars and should stay in your local `.env` or deployment environment. Do not commit real Firebase values.

## Notes

- The workout and nutrition content was ported from `sofit-nutrition-app.html`.
- New plans are generated by the `generatePersonalPlan` callable Cloud Function and saved into Firestore.
- Exercise guidance now uses form cue cards instead of the earlier abstract stick-figure animations.
- Firestore offline persistence is enabled with Firebase's persistent local cache, so the app can continue from cached data and sync when online again.
- Any future AI helpers should also be added through Firebase Cloud Functions only, with model API keys kept server-side.
